# AI 教练口诀战术

教练只使用自己的手牌、公开出牌与不要、各家剩余张数和公开进贡信息。下面的口诀均实现为有条件的候选偏好或代价，不是对隐藏手牌的断言；能一手合法出完时优先走完。权重是启发式参数，不保证最优或真人水平。

| 口诀 | 当前实现 |
| --- | --- |
| 情况不明，对子先行 | 本局公开出牌不足 10 张时，首出对子获得试探优惠。 |
| 有鬼打一张，无鬼打一夯 | 开局持王时小单有试探优惠；无王时三带二有整理牌型优惠。 |
| 不能做头游，单张暂缓走 | 用控牌、炸弹和相对余牌粗估牌力；估计偏弱且落后时提高小单代价。对手仅剩一张时改按紧急局面与未知大牌评估。 |
| 两个小单张，不打不健康 | 估计有争先条件且至少两个小单时，首出小单获得优惠。 |
| 枪打第一顺，轻易不组顺 | 利用全局公开历史识别对手首次顺子，为可用炸弹提供拦截优惠；拆散余牌组顺则增加代价。炸弹仍与普通牌和风险比较。 |
| 想使坏，三不带 | 牌力估计偏弱且仍有对手剩至少 5 张时，为三张试探对手结构提供优惠。 |
| 强牌弱打，弱牌强打 | 牌力较强时适当保留大牌；牌弱时适当提高大牌争节奏的意愿。 |
| 有打要有收，出牌不白丢 | 首出比较余牌中是否保留级牌、王或炸弹；不足控牌时提高出牌风险，不能保证实际收回。 |
| 逢五出二，逢六出三 | 有对手剩 5 张时对子获得优惠；剩 6 张时三张获得优惠。 |
| 七张、八张正常出夯 | 有对手剩 7 或 8 张时，三带二或顺子获得优惠。 |
| 炸五不炸四，枪不打四 | 上家剩 5 张时增加用炸拦截意愿；剩 4 张且我方未接近走完、其他对手也不紧急时，倾向保留炸弹。 |
| 九张当作五张打，十打二来九打一 | 对手剩 9 张时单张和对子获得试探优惠；剩 10 张时对子获得优惠。 |
| 残局沉住气，不用枪打四 | 复用剩 4 张的保炸条件；存在紧急威胁或自己接近走完时仍可用炸。 |
| 除单慎接对家牌，只有牌好才接牌 | 队友领先通常让牌；可一手走完、保护队友的紧急单张，或己方牌力较强而对手接近走完时可以接管。 |
| 牌不好时学会让，让给对家不上当 | 估计牌弱且队友仍有跟牌机会、对手不紧急时降低自己的跟牌代价上限；队友领先通常让牌。 |
| 对家要啥就给啥 | 队友近期公开出牌至少两次呈现相同非炸弹牌型，且对手不紧急时，为相应的小牌提供递牌优惠；队友只剩 1–2 张时也考虑单张或对子。历史出牌只能作为弱线索。 |

教练在人类出牌回合先提供基础建议，在后台按最多 3 秒比较全阶段候选行动；结果经完整相同样本和稳定性门槛检验后可更新建议。教练自己的回合也在后台计算，超时回退基础策略。搜索最多比较 6 个候选、12 组未知手牌样本，每个样本内候选共享同一组分牌；开中局最多推演 12 步，残局最多 48 步。对手和队友只在模拟世界持有按公开信息采样的可能手牌，不使用其真实隐藏牌。更多样本和口诀偏好不保证搜索强于基线。
